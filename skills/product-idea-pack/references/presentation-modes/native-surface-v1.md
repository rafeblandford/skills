# Presentation mode: Native Surface

**Identifier:** `native`  
**Use with:** product storyboard and interactive prototype

Use this mode when an intervention must be judged inside the real product, platform, service or device where it would live. The host supplies the visual language; Product Idea Pack supplies the proposition, truth labels and discussion framing.

## What changes

- Reproduce host geometry, hierarchy, spacing, navigation logic and component conventions closely enough to make the intervention credible.
- Keep the editorial wrapper secondary to the product surface.
- In the opening view, let the host or product intervention occupy roughly two thirds or more of the visible area. Keep the wrapper compact rather than leading with a poster-sized title.
- Show only enough surrounding product to locate and judge the intervention.
- Preserve realistic device proportions and safe areas; never squash the host to fit a slide.
- State which surrounding behaviours, data or integrations are simulated or omitted.

## Reference needs

Use an existing screenshot, design-system link or supplied product description when the host exists. Ask for one only when it is not already present and invention would materially change the judgement. If no host exists, use a clearly neutral product shell.

Borrow structure and interaction conventions, not protected assets, misleading logos or pixel-for-pixel decoration. Never make an unaffiliated concept appear official.

## Reject when

- the surrounding product overwhelms the proposed intervention;
- the editorial house style overwhelms the host surface;
- a generic dashboard substitutes for the real product context;
- the host appearance implies false affiliation; or
- visual fidelity disguises illustrative data or missing behaviour.
