# Return Marker input

Explore a specific feature inside an existing long-form reading product.

When somebody returns to a long article, report or essay after an interruption, restore them to the last paragraph they meaningfully read and offer a compact recap of the preceding section. The recap must be optional and dismissible. The feature should reduce searching and rereading without taking over the reading experience.

Create a product concept scamp, not an HTML prototype. Show only enough of the surrounding reading product to locate the feature. The uncertainty to expose is whether the recap restores context or interrupts re-entry.
