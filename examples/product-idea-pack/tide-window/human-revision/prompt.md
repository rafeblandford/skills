# Tide Window — source brief

This is a fresh one-shot validation run of Product Idea Pack revision `007ade1`.

Create a neutral, shareable product-idea example for people deciding when to visit the beach or use the sea.

The product is a glanceable phone lock-screen or desktop widget for UK locations. It should show the current predicted tide height, whether the water is rising or falling, the current position on a tide curve and the next turning point. A person can move from that glance into future days.

The example must help test whether the same proposition remains coherent across four formats:

- scanned sketch-page;
- editable line-board;
- product concept scamp;
- standalone HTML prototype.

The central uncertainty is whether the curve creates useful confidence or too much density at lock-screen size. All values are illustrative. Tide prediction must not imply coverage of weather, warnings or local hazards.

Run constraints:

- create Draft 1;
- use the brief above as the only concept input;
- do not inspect or reuse earlier Tide Window material;
- perform normal visual, interaction and export QA;
- record source revision, harness and zero human-feedback rounds;
- do not commit the results.
